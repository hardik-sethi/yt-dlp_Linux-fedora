# yt-dlp_Linux-fedora
Interactive Youtube video download with multiple options and aria2 download manager. (Require yt-dlp, ffmpeg, aria2)


# To Run

```bash
chmod +x yt-grab.sh
./yt-grab.sh
```

# May Require

## Install Deno (Fedora)

```bash
curl -fsSL https://deno.land/install.sh | sh
```

## Install aria2

```bash
sudo dnf install aria2
```

## Install curl-cffi

```bash
pip install -U curl-cffi
```

## Install Python Brotli Support

```bash
sudo dnf install python3-brotli
```
