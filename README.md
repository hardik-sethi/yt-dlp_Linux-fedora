# yt-dlp_Linux-fedora
Interactive Youtube video download with multiple options and aria2 download manager. (Require yt-dlp, ffmpeg, aria2)


To Run-
    chmod +x yt-grab.sh
    ./yt-grab.sh


May Require:-
    install deno in fedora
    sudo dnf install aria2
    pip install -U curl-cffi
    sudo dnf install python3-brotli
